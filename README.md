# امروز

برنامه‌ریز مینیمال فارسی با تاریخ شمسی، ساعت ۲۴ ساعته و ذخیره‌سازی محلی.

## اعلان‌ها

- یادآوری پنج دقیقه پیش از زمان هر کار
- اعلان دوباره در زمان شروع کار
- خلاصهٔ نیم‌روز در ۱۱:۵۵
- خلاصهٔ پایان روز در ۲۳:۵۵

در نسخهٔ PWA، اعلان‌های دقیق هنگامی تضمین می‌شوند که برنامه باز یا در پس‌زمینهٔ مرورگر فعال باشد. اعلان‌های دقیق پس از بسته‌شدن کامل برنامه به بسته‌بندی بومی Android و AlarmManager نیاز دارند.

## اجرای پیش‌نمایش

در این پوشه اجرا کنید:

```powershell
node server.js
```

سپس `http://localhost:4173` را باز کنید.

این نسخه PWA است و از منوی مرورگر Android با گزینه **Add to Home screen** نصب می‌شود. برای خروجی APK بومی، Android SDK و Gradle باید روی سیستم نصب شوند.

## Android APK

پوشهٔ `android-app` یک پوستهٔ بومی Android برای برنامه است. این نسخه وظایف را با Android همگام می‌کند، اعلان‌های پنج دقیقه قبل و سر وقت را با AlarmManager می‌فرستد، خلاصه‌های نیم‌روز و پایان روز را در پس‌زمینه محاسبه می‌کند و پس از راه‌اندازی دوبارهٔ تلفن زمان‌بندی را بازیابی می‌کند.

برای ساخت محلی با Gradle 8.9 و JDK 17:

```powershell
gradle :android-app:assembleDebug
```

GitHub Actions نیز پس از هر push فایل APK را به‌عنوان artifact با نام `anjam-bede-apk` تولید می‌کند.
